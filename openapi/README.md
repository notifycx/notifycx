# OpenAPI

`openapi.yaml` is a **vendored copy** of Notify’s public API specification.

**Live source of truth:** https://notify.cx/openapi.yaml

When the Notify API docs change on the product site, refresh this file from that URL (or from the Notify app repo’s `openapi.yaml`) and bump examples/tests if request shapes change.

Do not invent endpoints here that are not on notify.cx.
